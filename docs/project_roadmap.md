# 365MEOプロジェクト 進行計画書（ロードマップ）

- **策定日**: 2026年7月14日
- **開発パートナー**: 株式会社ジラーチ

本ドキュメントは、365MEOシステム（365meo-app / thanxcreate-app - システム名称「MEO SEIHA」）の開発における「デモ版」と「本番（製品版）」の相違定義、リリーススケジュール、各種API・AIキーの役割分担、およびテスト計画をまとめた進行計画書です。

---

## 1. プロジェクト基本方針（アーキテクチャ）
将来的にそれぞれのブランド（365meo / Thanxcreate）が独自のカスタマイズや機能追加をそれぞれの裁量で自由に行えるよう、スタート時点から**「2つの完全に独立したリポジトリ（ソースコード）、独立したサーバー、独立したデータベース」**として物理的に分離してクローン構築します。
※これにより、お互いのシステムアップデートが干渉せず、顧客情報（データ）の完全隔離による高度なセキュリティが担保されます。

---

## 2. デモ版 と 本番（製品版）の定義・違い

| 比較項目 | デモ版（7月中リリース目標） | 本番（8月中旬リリース目標） |
| :--- | :--- | :--- |
| **主な目的** | 裏側の自動化プログラム（コア機能）の正常動作確認。 | 一般オーナー様が実際に利用する商業用製品の完成。 |
| **データ連携** | モック（システム内のダミーデータ）で安全に検証。 | 本物のGoogleマップ（GBP）の店舗データと連動。 |
| **管理画面UI** | **最低限の簡素な画面**（お化粧・デザインは未適用）。 | **美麗な製品版UI**（ダッシュボード、グラフ、ログ）。 |
| **営業管理機能** | なし（ジラーチが裏側からテスト店舗を追加）。 | あり（営業スタッフがブラウザから店舗登録・解約処理）。 |
| **ログイン機能** | なし（または固定のテストアカウントのみ）。 | あり（店舗ごとに個別のID・パスワード制限。**ブラウザの自動ログイン保持機能、およびLINE通知リンクからの『ワンクリック自動ログイン（パスワード不要）』に対応**）。 |
| **インフラ構成** | ジラーチの検証用共同サーバー（1台）で同居稼働。 | 各社個別の独立した本番サーバー・DB（2セット）。 |
| **API接続環境** | 開発用のテストアカウント等を使用。 | 各社が契約した本番のLINEアカウントやAPIを接続。 |

## 3. 開発からリリースまでのスケジュール（ロードマップ）

### 【フェーズ1：デモ版開発】（7/15 〜 7/31）
- **7/15 〜 7/18 (環境準備 & 基本検証)**
  - THANX社からAPI接続キー2点（クライアントID、クライアントシークレット）を共有いただき、ジラーチにてGoogle接続テストを実施。
  - テスト用のGoogle Driveフォルダ、テスト店舗（GBP）、テストLINEアカウントの用意。
- **7/19 〜 7/25 (コア機能実装)**
  - Google Drive自動監視・自動投稿（AI生成 ✕ GBP API）の実装。
  - 口コミ自動返信（星3〜5定型ランダム ✕ 星1〜2AI下書き生成＆LINE通知）の実装。
- **7/26 〜 7/31 (デモ疎通テスト・リリース)**
  - モックデータを流し、画像投稿や口コミ返信・LINE通知の動作を3社で確認・デモ版完成。

### 【フェーズ2：本番開発・インフラ分離】（8/1 〜 8/15）
- **8/1 〜 8/7 (管理画面・ログイン機能の実装)**
  - 営業管理画面（CMS）およびログイン認証・権限管理の実装。
  - 口コミ履歴ログ・AI下書き編集送信画面の実装。
- **8/8 〜 8/12 (本番環境構築・デプロイ)**
  - 365meo用、Thanxcreate用の個別サーバー・データベースの独立構築。
  - 独自ドメイン・SSL設定、本番用APIキーの設定。
- **8/13 〜 8/15 (総合実機テスト・移行・正式リリース)**
  - デモ店舗を用いた「本物の星1口コミ」によるLINE通知・AI下書きの実機テスト（検証後口コミ削除）。
  - 本番店舗データの初期登録、本稼働開始。

## 4. APIおよびAIキーの役割分担

| 技術要素 | テスト・開発段階（デモ版） | 本番移行・稼働段階（本番版） | 取得・設定作業の担当 |
| :--- | :--- | :--- | :--- |
| **Google Drive API** | ジラーチのサービスアカウント | ジラーチのサービスアカウント | **ジラーチ（システム）**が取得・管理。<br>※各社様は普段のDrive上で「フォルダ作成し、システム用のアドレスを共有登録」するだけ。 |
| **LINE Messaging API** | 開発用のテストアカウント | 各社契約の本番用アカウント | **365 / THANX各社様**がLINE公式アカウント内で発行し、ジラーチへ共有。 |
| **Google GBP API** | THANX社所有のプロジェクト | THANX社 / 365社の各プロジェクト | **365 / THANX各社様**が取得。<br>※ジラーチへ「Client ID / Secret」の2点のみテキスト共有（デベロッパートークンは不要、ID/PASSログイン不要）。 |
| **AI (LLM) APIキー** | **ジラーチの開発用APIキー**<br>（テスト利用料はジラーチ負担） | **各社契約の本番用APIキー**<br>（各社クレカ決済と紐付け） | **365 / THANX各社様**がGemini/OpenAIでキーを発行し、ジラーチへ共有。 |

## 5. テスト計画：デモ版モックテスト ✕ リリース前実機テスト

### 5.1. デモ版（7月中）：モックデータによる安全なテスト
- **挙動**: システムに「星1の口コミが届いた」という架空のデータ（モック）をプログラム内部で意図的に流します。
- **結果**: 本物のGoogleマップには書き込まずに、管理画面上での「AIによる謝罪下書き生成」「LINEへの緊急通知」「管理画面での下書き編集・送信シミュレーション」のすべてを無傷で体験できます。

### 5.2. 本番リリース前（8/13〜15）：テスト店舗による実機テスト
- **挙動**: THANX社が管理者登録しているテスト店舗（GBP）に対し、本物のGoogleアカウントから実際に「星1」を投稿します。
- **結果**: 本番のネットワークでLINE通知やAI下書きが連動することを確認後、投稿したGoogleアカウントの履歴から口コミを削除します（本物のGoogleマップ上に一時的に公開されるため、確認後ただちに削除します。システムと店舗との連携・接続解除は何度でも繰り返しテスト可能です）。
